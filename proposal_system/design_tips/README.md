# design_tips

8단계 디자인화에서 참조할 비정형 팁을 넣는 폴더다.

작성 규격은 [비정형_디자인팁_MD_작성규격.md](../../outputs/비정형_디자인팁_MD_작성규격.md)를 따른다.

기본 규칙:

- 한 파일에는 하나의 팁만 담는다.
- `stage`, `category`, `roles`, `applies_when`, `avoid_when`, `inputs_required`를 반드시 적는다.
- 레퍼런스를 그대로 복제하지 말고 시각 언어로 번역하는 팁을 우선한다.
- `anti_patterns/`의 팁은 최종 검수에서 항상 확인한다.
