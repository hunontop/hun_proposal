## ④ NEW-CANDIDATE — 어휘 밖 형태 (3그룹)

### 1. `feature_card_grid` (≈ `pillar_card`)
- **섬길 역할**: 병렬 특징·차별점·역량·서비스 라인을 비수치 아이콘+제목+설명+번호의 동일 규격 카드로 3~5열 나열(대등 위계).
- **카드 근거**: [[n열-아이콘-카드-그리드]] · [[번호-배지-분할-구성]]
- **수요플래그**: **[수요확인]** — 5차 run `gen_R26BK01623020-000` slide 3·5·7·9에서 catalog_gap 4건 실측(원전 앵커 P2.3+R6). `CONTEXT/DESIGN_ASSETS_LANE.md` §5-③에 이미 다음 실사용 사례로 예정.
- **원전체크 필요**: 이 조각이 정당하려면 원전 표현원칙의 어느 message_type(강점/차별점/역량 소개 계열로 추정)이 이 형태를 부르는지 확인 필요 — `source` 확정 시 P2.3 1회 대조(§5-③ 지시사항).

### 2. `cover_divider`
- **섬길 역할**: 표지·챕터 간지 전환 페이지 — 대형 워터마크 숫자/여백 지배+제목 블록 모서리 배치, 또는 얇은 선+라벨 위계로 문서 전환 리듬을 표시.
- **카드 근거**: [[대형-숫자-워터마크-표지]] · [[챕터-간지-여백]] · [[표지-라벨-제목-얇은선]]
- **수요플래그**: [대기-콘텐츠미확인] — 실 run에서 표지/간지 catalog_gap 확인된 바 없음.
- **원전체크 필요**: (a) 이 형태를 부르는 message_type이 원전에 있는지, 아니면 표지/간지 자체가 pieces.json의 "콘텐츠 조각" 범위 밖(별도 템플릿 시스템)인지부터 확인 필요 — 렌더러에 기존 cover 처리 경로가 있는지 먼저 점검 후 신설 여부 판단.

### 3. `section_nav`
- **섬길 역할**: 매 본문 슬라이드 상단에 고정 위치·서식으로 섹션 탭/단계 라벨(예: STEP 01, Analysis·Target·Ideation)을 반복해 "현재 위치"를 지속 표시(목차 전체 나열이 아니라 현재 강조).
- **카드 근거**: [[큰맥락-먼저]]
- **수요플래그**: [대기-콘텐츠미확인]
- **원전체크 필요**: `agenda` 조각(목차, 장르 규범)의 반복형 확장인지, 별도 원칙(장르 규범 밖)인지 확인 필요 — 어휘 주권=원전(결정 12) 기준으로 agenda와 분리된 별도 조각 자격이 있는지 판단 보류.
