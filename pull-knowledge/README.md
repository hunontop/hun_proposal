# pull-knowledge — 검색해서 당겨 쓰는 지식 라이브러리

이 폴더는 파이프라인이 **자동으로 주입하지 않습니다.** 분석·메시지맵·스토리라인·와이어프레임 단계에서
LLM(또는 사람)이 **필요할 때 검색해서 당겨(pull)** 쓰는 참고 지식의 단일 위치입니다.

- config 1점화: `proposal_system/config/pipeline.config.json` → `knowledge.pull_knowledge_dir` = `../pull-knowledge`
- 소비 방식: search-first — 통독하지 말고 지금 필요한 카드 1개만 찾아 읽는다.

| 폴더 | 무엇 | 언제 |
|---|---|---|
| `기획지식/` | 제안 기획·전략·메시지 설계 노하우 카드 | 분석 → 메시지맵 → 스토리라인 |

> **여기에 당신의 카드를 넣으세요.** 하위에 `.md` 카드를 자유롭게 놓으면 됩니다.
> (개발 원본 vault는 이 폴더 안을 `기획지식/메시지설계/`·`기획지식/경험설계/` 두 층으로 더
> 나눕니다. 이 배포판은 최소 구조라 `기획지식/` 통짜로 유지하되, 카드가 늘면 같은 방식으로
> 하위 폴더를 나눠도 됩니다.)

## 나중에 (3단계 이후, 선택)

와이어프레임(형태)·테마(색·디자인)까지 가면 같은 방식으로 `디자인지식/와이어프레임/`·`디자인지식/테마/`를 추가.
**층 격리**: 와이어프레임(형태) 단계에서 `테마/`(색·폰트)는 당기지 않는다(색이 형태 판단에 새면 오작동).
